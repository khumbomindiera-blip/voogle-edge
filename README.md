# Voogle Edge

Voogle Edge is an offline-first multilingual AI platform designed to improve access to agricultural knowledge and supply chain intelligence in rural Africa.

Built as an evolution of the original Voogle ("Village Google") concept, Voogle Edge enables farmers, extension officers, and rural communities to access localized agricultural information without requiring continuous internet connectivity.

## Features

* Offline AI agricultural assistant
* English and Chichewa support
* Community reporting system
* Early warning alerts
* District intelligence dashboard
* Dyslexia-friendly interface
* Dark mode support
* Text-to-speech accessibility
* Future SMS integration

## Technology Stack

* Python
* Flask
* Ollama
* Local LLMs
* HTML/CSS/JavaScript

Agriculture
